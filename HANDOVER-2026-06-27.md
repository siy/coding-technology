- `Booking.java` — `@Slice` with `buyTicket`/`cancelTicket`, nested `BuyError`/`CancelError` **record** variants, `Result.all` valid-request factories, factory injecting `@PgSql BookingPersistence`.
- `src/main/resources/com/example/ticketing/booking/routes.toml`, `src/main/resources/schema/V002__booking.sql` (seats + bookings, **no version column** — design-out).

**Authoritative Aether contract** (answered by the Aether coding agent, already folded in):
1. **Errors must be distinct `record` types, not enum constants** — `routes.toml` globs match the Cause **type simple name**, so multi-constant enums can't get per-status routing. (This revised our earlier nested-enum decision.)
2. **`@Query … RETURNING id` must return a single-field record** (`record RowId(UUID id)`), not a bare `Promise<Option<UUID>>` — the scalar column-name inferencer can't read `RETURNING` and fails at runtime.
3. Confirmed as-built: multi-statement guarded CTE in one `@Query`; `:name` bound by **param name**, repeated `:seatId` = one arg, native `UUID` binding; `@PgSql` interface as a slice-factory param wired into a nested inline `record booking(...)`; `snake_case→camelCase` row mapping.
4. DB failures surface as driver **`org.pragmatica.postgres.SqlError`** (NOT `DatabaseConnectorError`) — but we map all infra failures to one domain error at the boundary (`.mapError(_ -> StoreUnavailable())`), so it doesn't matter here.
