requires template conversions == `forNValues` N; `Causes.forOneValue("Payment step failed", PaymentFailed::new)`
has 0 conversions for N=1. So R-e as written makes every wrapper in the book (PaymentFailed ×2, DatabaseFailure,
PasswordHashingFailed, TokenGenerationFailed) a lint violation. Options to put to the owner:
1. Lint change: CAUSE-04 exempts the `origin` component of a `Cause.Wrapped` target (conversions == N − 1 when
   the record is Wrapped). Lands with the M7 lint rule.
2. Core helper for wrappers (e.g. a `Causes` rung taking a fixed message and `Fn2<C, Cause, String>`), so no
   template arity question arises. Core change → rc5.
3. Hand-written `FACTORY = origin -> new X(origin, "text")` — check against `JBCT-CAUSE-08` (direct
   construction) first.
