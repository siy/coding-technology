## Conventions in force (apply to all new drafting and revision)

- **Vignette** (italic, observational + small turn) at chapter top; **threads-advanced tag** at chapter foot. Voice doc §7 legitimizes foot position.
- **Em-dash ≤2 per prose paragraph.** Definition lists using "Term — definition" are exempt. `**Term.** body` definition-style lists are de-facto treated as exempt where the prose discipline is otherwise held.
- **Forbidden vocabulary** (never in publishable body): "non-functional" / "NFR" / "system-level requirement" / "system-input requirement". Use "quality requirements" / "system qualities" at the umbrella level; SLO / constraint / operational target / substrate-shaping at Phase-4 detail.
- **Forbidden domain vocabulary:** transit vocab (fares / transit / route — ticketing uses prices / tier prices / sales). No DDD/competitor/SOLID teardown register; present positively.
- **Product names:** none in publishable body, **except**:
  - **Aether** named where the slice deployment mode is doing genuine load-bearing work (see "Durable decisions" item 1).
  - **Positive crediting** to: Loth, King, Yevtushenko (Saga article), Poltorak.
- **Code:** pseudo-code for type shapes, Java for composition. JBCT idioms strict (single-param `Result<T>`, `Promise<T>` carries failure, I/O async, `Unit` not `Void`, `TypeName.typeName(...)` factories, method references, no `Promise<Result<T>>`, sealed `Cause`).
- **Composed-not-invented:** a unit owns only what its composition adds; it inherits its constituents' types.
- **Grouping beat** (Passes 2–4 only — formed-from-below altitudes): show what's grouped + change-driver character + recognition test. Within-altitude composition (six patterns, every altitude) ≠ cross-altitude grouping (change-driver cohesion, transitions only).
- **Register:** research-cited, sharp, observational; show-don't-tell; uniform commitment, varied form.
- **Citation style:** inline markdown link `[Title](url)` matching Loth / King / Saga / Poltorak treatment.
