## Conventions / gotchas

- **Per-book versions, single-sourced from each `CHANGELOG.md` top entry.** PFD build: `book-pfd-meta/build-pdf.sh --final` (default is draft). JBCT: `book/build-pdf.sh` (PDF) + `book/build-epub.sh` (EPUB); publish PDF+EPUB.
- **Leanpub publish:** `./publish-leanpub.sh <slug> <pdf> [epub] --publish` (slugs: `process-first-design`, `jbct-book`). It has two interactive y/N prompts — feed `printf 'y\ny\n' | ...`. The publish step returns a noisy **"Unexpected Server Error"** body that is **benign** — always verify `last_published_at` actually moved via `curl -s "https://leanpub.com/<slug>.json?api_key=$LEANPUB_API_KEY"`. Rate limit ~3 ops/min. `LEANPUB_API_KEY` is in the shell env.
- **UA reply style (calibrated this session):** blunt, first-person (`я`, not `ми`), straight ASCII quotes `"` (NOT `«»` — he switched mid-session), `-` not em-dash, `->` arrows, ASCII apostrophes, free transliteration (юз кейс, воркфлоу, каплінг, едж-кейс). Drafting flow: write to `scratchpad/replyN.txt` via a python heredoc that asserts no forbidden chars (em-dash/smart-quotes/modifier-apostrophe/guillemets/NBSP/arrow), then `pbcopy`. Single-line conventional commits, no attribution.
- **Books are never committed** (PDF/EPUB gitignored). Tag only on explicit command.
