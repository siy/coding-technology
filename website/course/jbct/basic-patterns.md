## blurb
The three basic patterns - Leaf, Condition, Iteration - and mechanical rules for extracting functions.

## learn
- When to extract functions (mechanical rules, not judgment calls)
- Single level of abstraction
- Leaf, Condition, Iteration
- Zone-based naming conventions

## note
Most of your daily code is Leaf, Condition, and Iteration. Master these three before moving on to
composed patterns.

## exercise
### Implement a Condition Router | ~15 min
Build a step that routes to one of three behaviors based on a discriminator field (a user tier, a
status enum, a message type) using a switch expression that returns the same type from every branch.
Solution discussion in the book's Appendix B (Exercise 3.3).
