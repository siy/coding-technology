## Where this is heading

Process-First Design describes the system; JBCT writes it in Java; [Pragmatica Aether](https://pragmaticalabs.io/aether.html) — a distributed runtime currently in pre-release development — is where the same composition will deploy unchanged. One discipline from design to deployment.
