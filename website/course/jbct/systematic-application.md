## exercise
### Run the Checkpoints | ~15 min
Take a method or class from your own codebase, or a recent PR, and run it through the 8 checkpoints:
lambdas, return types, factories, class design, chains, logging, review, implementation patterns. List
every violation found. Solution discussion in the book's Appendix B (Exercise 6.1).
