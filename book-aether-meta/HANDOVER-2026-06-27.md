## Module D — durable workflow / saga (spec v0.2 ready)
- **Spec:** `../pragmatica/aether/docs/specs/durable-entity-primitive-spec.md` — hardened to
  **v0.2** this session by the `durable-design` agent (uncommitted in the pragmatica repo).
  Epic **#345**; pieces #350 (per-key queue), #351 (timers), #352 (DurableEntity core), #353
  (PersistentWorkflow facade, was #190), #354 (Saga facade + run-once), #355 (observability);
  persistence epic **#349**.
- **Model:** one primitive `DurableEntity<K,S>` (fenced single-writer, partition-placed,
  per-key serialization, state-as-truth / NO replay, durable timers). `PersistentWorkflow<S,E>`
  = entity + FSM (`StateMachineDefinition`). `Saga<C>` = entity + step ledger + reverse
  compensation + optional journaled run-once step. Side effects stay in slice code.
- **v0.2 correction (important):** the KV-path fence is **already live** (`staleEpochWrite` +
  `EpochBearing`, `KVStore.java:87-127`); #345 piece 1a is DONE. The remaining gap is the
  **stream-path** epoch fence (piece 1b, `OffHeapRingBuffer.java:330`). Durability still gated on
  #349 (storage is memory-only today: HA, not restart-durable). So Module D idioms are
  **spec-stage / prototype-pending**, not yet runnable end to end.
- **Pinned author-facing API (v0.2)** — what the book will teach (all methods
  `Promise<Result<...>>`, JBCT-correct):
  - `DurableEntity<K,S>`: create/get/update(mutator)/scheduleTimer/cancelTimer/delete.
  - `PersistentWorkflow<S,E>`: start/dispatch(event)/current/scheduleTimer/cancelTimer/delete.
  - `Saga<C>`: run(id, context)/status/delete; `SagaStep<C,R>(name, forward, compensation)`;
    sealed `SagaResult<C>` {Succeeded|Compensated|PartiallyCompensated|Failed};
    sealed `SagaState<C>` {Running|Compensating|Completed|Compensated|PartiallyCompensated|Failed}.
- **Saga baseline for the chapter (from realworld-explorer):** `jbct-realworld`'s
  `LoanOrchestrator` is a real, working, hand-rolled saga (ValidLoanApplication
  parse-don't-validate; context-accumulation records; `Promise.all` fork-join credit+collateral;
  `onFailure` compensation via `releaseHold`/`reverseBooking`; fire-and-forget notify via
  `.recover()`). Draft Module D as: this manual baseline first, then the durable `Saga` facade as
  the evolution. CAVEAT: reference repos lag current source (realworld pins aether 0.7.4; loan
  reportedly 0.17.0) — verify any idiom against current `../pragmatica`.
