## exercise
### Design CancelOrder | ~25 min
Design a use case interface for "Cancel Order": validate the order exists and belongs to the user,
only pending orders can be cancelled, refund if already charged, notify on success. Write the
interface, the step interfaces, and the factory method - no implementation needed yet. Solution
discussion in the book's Appendix B (Exercise 5.1).
