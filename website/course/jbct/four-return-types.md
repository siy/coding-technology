## blurb
The four return types - T, Option, Result, Promise - and the decision rule for choosing between them.

## learn
- Why exactly four return types are sufficient
- When to use each: T, Option, Result, Promise
- How to convert between types (lifting)
- Why Optional and CompletableFuture fall short

## exercise
### Return Type Selection | ~10 min
For six methods in your own codebase (a pure calculation, an optional lookup, a parser, a remote call,
a validator, a cache read), write down which of the four return types each should use and why.
Solution discussion in the book's Appendix B (Exercise 1.1).
